# Forme Realty — concept website

A responsive frontend-only real estate landing page concept built with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser or serve this folder using any static file server.

## Interactions
- Responsive navigation
- Filter sample listings by buy/rent, property type and location
- Save/unsave sample properties (client-side visual state only)
- Property enquiry dialog
- Contact form validation and demo confirmation
- Empty state and reset filters

## Important
Forme Realty is fictional. All listings, prices, availability and agency details are sample content, not real offers. Forms do not transmit or save submissions. Images load from Unsplash and fonts load from Google Fonts; replace with appropriately licensed/local assets before production.
