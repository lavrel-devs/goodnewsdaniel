# Northstar Academy — concept website

A responsive, frontend-only school website concept built with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser, or serve this folder with any static file server.

## Interactions
- Responsive mobile navigation
- Anchor navigation between school sections
- Admissions enquiry form with client-side required-field validation and demo confirmation
- Responsive layout and reduced-motion support

## Important
Northstar Academy is fictional and this is a portfolio concept. The admissions form does not transmit or store submissions. Classroom photography loads from Unsplash, and Google Fonts are external assets. Replace these with licensed/local assets before production use.
