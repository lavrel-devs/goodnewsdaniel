# Goodnews Daniel — Demo Projects

Two standalone, responsive frontend-only portfolio concept sites:

- `northstar-academy/index.html` — school website with responsive navigation and a demo admissions form.
- `forme-realty/index.html` — real estate site with sample property filters, save buttons, enquiry dialog and demo contact form.

Both are fictional concept projects. No form sends or stores data. Property prices/listings are illustrative. Images and fonts use external providers as documented in each project README.

Open either `index.html` directly, or deploy each folder to any static hosting service. For portfolio use, the updated portfolio project links are relative to the folder structure in this bundle.
