# Goodnews Daniel — Portfolio Website

A responsive, static portfolio for a Nigerian web designer/developer. Built with plain HTML, CSS and JavaScript; no build step or framework required.

## Preview locally
Open `index.html` in a browser, or run a local static server from this folder.

## Before publishing
1. Open `script.js` and replace `2348012345678` in `WHATSAPP_NUMBER` with your own WhatsApp number in international format, digits only (for example, `23480...`, no `+`, spaces, or leading `0`).
2. Review your name, project descriptions, PrepHQ scope and community growth figure for accuracy.
3. Add your email, GitHub, LinkedIn, and live project links if you want them displayed.
4. The Northstar Academy and Forme Realty items are explicitly marked as concept projects, not client work.
5. Confirm that the PrepHQ community growth statement is accurate and that you are comfortable publishing it.

## Deploy
Upload the folder to Netlify, Cloudflare Pages, GitHub Pages, or any static web host. No server or database is required for the portfolio. The contact form opens WhatsApp and does not store form submissions.
